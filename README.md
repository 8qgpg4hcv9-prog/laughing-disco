# laughing-disco
本项目从底层原理出发，完整实现了一个 BLDC 无刷电机的有感六步换相控制系统。  硬件采用 STM32F103C8T6 作为主控，搭配正点原子 ATK-PB6010B 三相无刷驱动板，通过 TIM1 高级定时器输出 6 路互补 PWM，利用硬件死区防止上下桥直通。系统通过三路霍尔传感器检测转子位置，查换相表实时切换 MOS 管导通状态，使定子磁场跟随转子旋转。  项目实现了完整的电机控制功能，包括正转、反转、能耗制动、PWM 无级调速，并支持按键切换状态机、旋转编码器作为调速旋钮。调试过程中使用示波器观察相电压波形，验证了互补 PWM 和死区设置的正确性。
